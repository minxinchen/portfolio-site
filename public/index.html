03 / WORKING METHOD

我處理問題與 AI 協作的三條原則

不誇大個人手寫程式能力，也不把 AI 或開源作者的貢獻算成原創；重點是把問題定義對、把邊界畫清楚、把結果測出來。

01 // PROBLEM FIRST◎

先做最小實驗，再決定架構

不先堆複雜框架。先跑原型確認瀏覽器 CORS、首屏瓶頸或資料缺失邊界，確認假設成立再投入正式實作。

02 // BOUNDARIES⌘

定性權留給人，執行交給協作

檔案改錯可以 git revert，但需求定義與概念定性權交出去很難奪回。善用不同工具釐清邊界與執行，最終驗收由人把關。

03 // EVIDENCE▤

誠實揭露限制與陰性結果

用公開資料、自動化測試與 CI 檢驗成果；分清楚已證實結果、待驗證假說與設計藍圖，不把未來式寫成現在式。
