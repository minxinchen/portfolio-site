原始問題

每日追蹤新技術很容易變成單純的工具清單：比較窗口不一致、研究進度中斷、重複推薦看過的專案，或把尚未實作的構想寫成已驗證成果。

雙線做法

將 GitHub 技術雷達與 AIoT 微課拆成兩條獨立生產線，共用來源查證、4 道 Quality Gate（Star 可比較性、Case Study 可驗收性、AIoT 初學者邊界、寄送失敗處理）、HTML 電子報編排及持久化執行紀錄。

實際產物

已建立完整的 HTML Workflow Blueprint（v1.0）；2026/10/30 至 11/04 產出並寄出 6 期個人研究電子報，涵蓋 GitHub 專案分析、實驗提案與 AIoT Day 1–3 微課。
